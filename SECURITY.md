# Security Policy

## Supported Versions

Only the latest published version of ShipGuard is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The ShipGuard maintainers take security seriously. If you discover a security vulnerability within ShipGuard, please report it privately.

**Please DO NOT submit public issues or PRs containing vulnerability details.**

### How to report:
1. Email: `danielachmadf@gmail.com`
2. Subject: `[SECURITY] ShipGuard Vulnerability Report`
3. Provide details:
   - Description of the issue and potential impact
   - Minimal reproduction repository or steps
   - Proposed mitigation or patch if available

### Response Timeline:
- Initial acknowledgment: within 48 hours
- Vulnerability assessment & patch timeline: within 7 business days
- Public release and advisory: following patch verification
